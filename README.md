One original fortune-cookie line for a software developer, written by this program for make.fun's "Fortune Cookie Wisdom for Developers" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
